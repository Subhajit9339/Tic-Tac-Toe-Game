### ❌ Tic-Tac-Toe Game ⭕

A clean, modern, and fully responsive Tic-Tac-Toe (Noughts and Crosses) game built from scratch using vanilla web technologies. Play with a friend locally on the same screen! 

### 🚀 Features

* **Interactive Gameplay:** Smooth click handling and real-time turn indicators.
* **Responsive Design:** Completely mobile-friendly; plays beautifully on phones, tablets, and desktops.
* **Win/Tie Detection:** Automatically detects and highlights winning combinations or declares a draw.
* **Score Tracker / Reset:** Easily restart the match with a single click without refreshing the page.

### 🛠️ Technologies Used

* **HTML:** For the semantic game structure and grid layout.
* **CSS:** For modern styling, grid centering, animations, and responsive layouts.
* **JavaScript :** For game logic, turn management, and win-condition checking.
